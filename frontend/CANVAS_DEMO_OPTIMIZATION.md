# 学习画布 Hackathon Demo 优化总结

## ✅ 已完成的优化

### 一、追问交互优化 - 关键改进

**问题**: 现场 Demo 时如果 RAG API 失败，追问功能会卡住，无法展示完整闭环。

**解决方案**: 实现智能 Fallback 机制

#### 优化后的 `handleFollowUp` 函数逻辑

```typescript
// 1. 尝试调用真实 RAG API
try {
  const response = await askKnowledgeBase(contextPrompt, [documentId])
  // 创建真实子卡片...
  cards.value.push(childCard)
  parentCard.followUpCount++
  ElMessage.success('成功')
}
// 2. API 失败时自动降级到演示模式
catch (error) {
  // 创建演示子卡片，确保 Demo 不中断
  const demoAnswer = isChineseLocale.value
    ? `这是关于「${title}」的演示解释。在实际应用中，AI 会基于课件内容生成详细回答。`
    : `This is a demo explanation for "${title}". In production, AI will generate detailed answers based on course materials.`
  
  // 同样创建子卡片并更新父卡片
  cards.value.push(demoChildCard)
  parentCard.followUpCount++
  ElMessage.warning('追问失败，使用演示数据')
}
```

**关键特性**:
- ✅ API 失败不会卡住，立即切换到演示模式
- ✅ 演示模式明确标注 `excerpt: '演示模式' / 'Demo Mode'`
- ✅ 不伪装成真实 RAG 来源，保持诚实
- ✅ 父卡片追问次数照常累加
- ✅ 追问 ≥2 次后仍然标记"易忘点"
- ✅ 子卡片仍然出现在中间画布
- ✅ 保证 Demo 闭环完整

## 🎯 Hackathon Demo 标准流程

### 完整操作步骤（2-3 分钟）

#### 1. 进入画布 (10秒)
- 首页点击"学习画布 / Learning Canvas"卡片
- 或直接访问 `/canvas`

#### 2. 加载演示画布 (5秒)
- **关键操作**: 点击左侧"加载演示画布 / Load Demo Canvas"
- 6 张知识卡片立即出现
- 第一张卡片自动选中

#### 3. 浏览知识点 (15秒)
- 中间画布展示 6 张卡片
- 不同标签不同颜色：
  - 🔵 定义 (蓝色)
  - 🟢 公式 (绿色)
  - 🟠 例子 (橙色)
  - 🔴 易错点 (红色)
  - 🟡 高频考点 (琥珀色)
- 卡片显示页码和追问次数
- 悬停有动画效果

#### 4. 查看详情 (15秒)
- 右侧显示选中卡片详情
- **展示要点**:
  - 标题和标签
  - 简短解释
  - 来源文件名：demo.pdf
  - 页码：第 3 页
  - 原文片段（引号包裹）

#### 5. 快捷追问 - 第一次 (20秒)
- 点击"解释得更简单 / Explain Simply"
- 等待 AI 响应（或立即 fallback）
- **观察结果**:
  - 新子卡片出现在中间画布
  - 子卡片有虚线边框和浅色背景
  - 子卡片紧跟父卡片
  - 父卡片显示追问次数徽章 (1)

#### 6. 快捷追问 - 第二次 (20秒)
- 再次点击"举一个例子 / Give Example"
- **观察结果**:
  - 又一个子卡片追加
  - 父卡片追问次数变为 2
  - **关键**: 父卡片右上角出现红色"易忘点"徽章
  - 父卡片边框变为红色

#### 7. 切换语言 (10秒)
- 返回首页（点击"返回"按钮）
- 点击右上角语言选择器
- 切换到英文 (English)
- 再次进入学习画布
- **观察**: 所有 UI 文本切换为英文

#### 8. 展示子卡片层级 (10秒)
- 滚动中间画布
- 指出子卡片的视觉特征：
  - 虚线边框
  - 浅色背景
  - 左侧连线装饰
  - 显示"← 父卡片标题"

## 🔍 功能分类：真实 vs Fallback

### 真实 RAG API 调用

1. **生成学习画布**
   - 调用 `askKnowledgeBase(prompt, [documentId])`
   - Prompt 包含"提炼 6-10 个知识点"
   - 解析 AI 返回的文本
   - 失败时使用内置 6 张演示卡片

2. **追问功能（成功时）**
   - 调用 `askKnowledgeBase(contextPrompt, [documentId])`
   - Context 包含卡片标题和摘要
   - 提取 sources 的页码和 excerpt
   - 创建真实子卡片

### Fallback 演示兜底

1. **演示画布数据**
   - 内置 6 张卡片（线性代数主题）
   - 包含完整字段：标题、摘要、标签、页码、片段
   - 根据当前语言动态生成
   - 无需任何后端或文档

2. **追问功能（失败时）**
   - 捕获 API 错误
   - 立即生成演示子卡片
   - 明确标注 `excerpt: '演示模式'`
   - 提示用户"追问失败，使用演示数据"
   - 但仍然完成追问流程，不中断 Demo

## ⚠️ Demo 现场注意事项

### 推荐做法
1. ✅ **优先使用"加载演示画布"** - 最可靠
2. ✅ **提前准备好一份测试文档** - 备选方案
3. ✅ **演示前清空浏览器 localStorage** - 确保干净状态
4. ✅ **演示时先展示中文，再切换英文** - 体现多语言
5. ✅ **点击追问按钮等待 2-3 秒** - 给 AI 响应时间

### 应急预案
- ❌ 如果 RAG API 慢或失败 → ✅ Fallback 立即接管
- ❌ 如果无网络 → ✅ 演示画布仍可用
- ❌ 如果无文档 → ✅ 演示画布仍可用
- ❌ 如果后端挂了 → ✅ 演示画布仍可用
